# Maldives Commitment Board: review demo

A prototype of the commitment board for the 16 Days of Activism against gender-based violence, prepared by Next Group Pvt Ltd for proposal review.

This demo needs no server. Everything a visitor submits or approves stays in their own browser, and the data is sample data. It is not an official UNFPA site.

- Board: `index.html`
- Submission form: `submit.html`
- Reviewer page: `admin.html` (demo password: `demo`)
